
# Contributing to Open Loan Calculator

Thank you for your interest in contributing to this project!

## How to Contribute

You can contribute by:

- Reporting calculation errors.
- Suggesting new loan features.
- Improving the user interface.
- Improving documentation.
- Testing the application.

## Reporting Bugs

Please open a GitHub Issue and include:

1. Description of the problem.
2. Input values used.
3. Expected result.
4. Actual result.
5. Screenshot, if available.

Do not include personal financial or banking information.

## Suggesting Features

Open an issue describing:

- The proposed feature.
- Why it would be useful.
- How it could improve the application.

## Code Contributions

1. Fork the repository.
2. Create a separate branch.
3. Make your changes.
4. Test the calculations.
5. Submit a Pull Request explaining your changes.

## Financial Accuracy

Changes affecting loan calculations should include test cases and supporting calculation logic.

## Licence

By contributing, you agree that your contributions will be distributed under the project's MIT Licence.

Thank you for helping improve Open Loan Calculator!
